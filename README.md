## 3. Career Master

Repository: https://github.com/career-master/career-master.ai

Career Master is a full-stack learning management and assessment platform designed around user management, quizzes, batches, dashboards, authentication, and administrative workflows.

The repository contains separate frontend and backend applications and has a modular architecture with dedicated modules for authentication, roles, quizzes, batches, users, and dashboard functionality.

### Major Features

* User registration and login
* OTP verification
* JWT-based authentication
* Access and refresh tokens
* Role-Based Access Control
* Permission management
* User management
* Quiz management
* Excel-based quiz upload
* Quiz attempt tracking
* Automated scoring
* Batch management
* Student dashboards
* Performance analytics
* Administrative dashboard
* Dynamic statistics
* File upload functionality
* Email integration

### Technical Architecture

The backend is built using Node.js and Express with MongoDB Atlas as the database. Authentication uses JWT access and refresh tokens, while Zod is used for validation. Multer handles file uploads and XLSX is used for Excel processing.

The frontend uses Next.js, React, TypeScript, Tailwind CSS, and Chart.js for dashboard visualizations.

The application is structured into separate frontend and backend modules, including authentication, roles, quizzes, batches, users, and dashboard services.

### Deployment

* Backend: Render
* Frontend: Vercel
* Database: MongoDB Atlas

This is one of the stronger projects to highlight because the repository demonstrates a complete application architecture rather than only a basic CRUD application.
